Debian · Ubuntu (apt)

Add the signing key and the repository once, then install any SosomLab app with apt. Updates arrive with apt upgrade.

sudo curl -fsSLo /usr/share/keyrings/sosomlab-archive-keyring.gpg https://pkg.sosomlab.com/sosomlab-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/sosomlab.sources https://pkg.sosomlab.com/apt/sosomlab.sources
sudo apt update
sudo apt install nexa-clip

Fedora · RHEL · Rocky · AlmaLinux (dnf)

Add the repository once, then install with dnf. Updates arrive with dnf upgrade. On the first install dnf asks to import the signing key — check that its fingerprint matches the one below.

sudo curl -fsSLo /etc/yum.repos.d/sosomlab.repo https://pkg.sosomlab.com/rpm/sosomlab.repo
sudo dnf install nexa-clip

Remove

# apt
sudo apt remove nexa-clip
sudo rm /etc/apt/sources.list.d/sosomlab.sources /usr/share/keyrings/sosomlab-archive-keyring.gpg
sudo apt update
# dnf
sudo dnf remove nexa-clip
sudo rm /etc/yum.repos.d/sosomlab.repo
